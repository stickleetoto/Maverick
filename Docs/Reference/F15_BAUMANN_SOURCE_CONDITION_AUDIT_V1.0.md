# F-15 — Baumann/Davison Source-Condition Audit (V1.0, WP-3A)

> **Research configuration only** (`F15_AFIT_BAUMANN_DAVISON_MACH06_20K_RESEARCH`). **Nothing here touches NASA 836.**

**Question:** does "Mach 0.6 / 20,000 ft research model" mean

- **(A)** every simulated state stays at Mach 0.6, or
- **(B)** the coefficient data were fitted at Mach 0.6 / 20,000 ft, while the model's own dynamics vary airspeed and dynamic pressure?

**Answer: (B).** Mach 0.6 / 20,000 ft is a **coefficient-fit condition**. It is **not** a runtime simulation condition. The source code never computes Mach. It holds density at the 20,000-ft value and lets true velocity vary as a state.

**Sources read in the original listings, not in our docs:**
- Baumann, AFIT/GAE/ENY/89D-01 (DTIC ADA217366): the `D2ICCV28` driver, App. B, PDF pp.90–98, and its `COEFF`, PDF pp.98–117.
- Davison, AFIT/GAE/ENY/92M-01 (DTIC ADA256613):
  - the `STATE12` bifurcation driver, App. B, PDF pp.90–120;
  - the simulator, App. C, PDF pp.121–150. Its `COEFF` is the one Maverick transcribes.

## 1. What the code does — answers

| # | Question | Answer | Where |
|---|---|---|---|
| 1 | Is Mach a runtime state or input to the coefficient routine? | **No.** `COEFF` takes α, β, rates, surfaces and V. No Mach variable exists. The only "MACH" is a comment: coefficients "TAKEN DIRECTLY FROM THE 1988 F15 AEROBASE (0.6 MACH, 20000 FEET)". | Baumann PDF p.101; Davison PDF pp.103, 133 |
| 2 | Is Mach fixed anywhere in the simulation? | **Not as a runtime quantity.** Mach is fixed only as a property of the fitted data: "Two parameters not listed in the force and moment coefficient expressions are Mach number and altitude, which were fixed at 0.6 and 20,000 feet respectively." | Baumann PDF p.36 |
| 3 | Is altitude fixed at 20,000 ft? | **Yes, implicitly.** The 8-state model (`NDIM = 8`) has no altitude state. Altitude enters only through the density constant. | Baumann PDF pp.95–98 (FUNX, INIT) |
| 4 | Is density fixed at the 20,000-ft value? | **Yes.** "RHO - AIR DENSITY AT 20000 FT ALTITUDE, SLUG/FT^3", `RHO = .0012673`, for every state. | Baumann PDF p.91; Davison PDF pp.91, 124 |
| 5 | Does true airspeed vary independently? | **Yes.** `U(8)` is "TRUE VELOCITY, IN THOUSANDS OF FT/SEC", a state with its own equation `F(8)` (V-dot). | Baumann PDF pp.96–97; nomenclature p.13 |
| 6 | Is q = ½ρV² with the varying V? | **Yes.** `QBARS = .5*RHO*VTRFPS*VTRFPS*SREF` with `VTRFPS = 1000.*U(8)`. The equations of motion use `K1·V²` with `K1 = .5*RHO*SREF/RMASS`. | Baumann PDF pp.91, 95, 101 |
| 7 | Were the Table VII equilibria generated by that model? | **Yes.** "A compilation of stable low α equilibrium states … calculated for the F-15B as a function of stabilator deflection". They were computed by AUTO driving `D2ICCV28` + `COEFF`, with thrust fixed at 8,300 lb and altitude at 20,000 ft. | Baumann PDF pp.54, 124 |
| 8 | Which variables are continued? | The **free parameter** is `PAR(ICP)`, and `PAR(1) = DELESD`, the stabilator ("as a function of stabilator deflection"). The **solved states** are α, β, p, q, r, θ, φ and **V**. The other tables use `PAR(2)`, rudder, for their sweeps. | Baumann PDF pp.93, 97, 118, 124 |
| 9 | Does varying V mean the author intended off-Mach-0.6 operation? | **Mathematically yes, physically no claim.** The continuation runs the Mach 0.6 fit at every speed the equilibria reach, and the author accepts results below Mach 0.6 under an incompressibility assumption. Baumann: "Flight at Mach 0.6 can be assumed to be in the incompressible flow region" (p.36). He discounts velocities "much higher" than the 622.14 ft/s of Mach 0.6 (pp.118–119). Davison, after flight test: "The model aerodynamics were only valid at M=0.6", and results at lower Mach were "not physically realizable" (p.44). | as cited |

**Thrust** is `THRUST = 8300.`, "TOTAL A/C THRUST, LBS", constant for every state. It enters as `CX = … + THRUST/QBARS` and `CMM = CMM0 + THRUST*(0.25/12.0)/(QBARS*CWING)`, so the **force is constant** while its coefficient scales with 1/q. Baumann chose it as "the thrust setting for trim conditions (steady, level flight) at 0.6 Mach and 20,000 feet" (p.34).

**The continuation start point** is "a steady straight ahead climb (α, θ, δe) = (5.0, 12.02, −1.39)". Baumann's starting-point method finds θ and V "as a function of (α, δe)" (pp.48–49). So V is solved, not imposed.

## 2. What the code does vs what the authors claim

- **The code does:** it evaluates the Mach 0.6 fit at whatever true velocity the equilibrium or trajectory reaches, with density frozen at 20,000 ft. Table VII runs from 288.7 to 699.7 ft/s, and Tables III and V go down to 218.5 ft/s. That is implied Mach 0.21–0.67 at 20,000 ft. The source never computes it.
- **Baumann claims:** the model is valid for incompressible flow, taken to be Mach ≤ 0.6. Velocities "much higher" than 622.14 ft/s are discounted. Table VII nonetheless keeps equilibria up to 699.7 ft/s (second-half points 116–120), so his cut-off is not a strict 622.14. *(Correction to WP-2's audit, which called this an in-source inconsistency: the text says "much higher", not "higher".)*
- **Davison claims:** valid only at Mach 0.6.

**Source-exercised ≠ aerodynamically validated.**

## 4. Runtime Mach gate decision — OUTCOME B

The old gate (`MavF15BaumannMach06Reference.NumericalMachTolerance = 0.001`) treated the fit condition as the only admissible *state*. That is **semantically too strong** for reproducing the source, and **correct** for the coefficients' own validity. It was not deleted. It is now one of two explicit modes, `MavF15ResearchConditionMode`:

| Mode | Admits | Reports |
|---|---|---|
| **`StrictFitCondition`** *(default)* | Mach 0.6 ± 0.001 at 6,096 ± 1 m — the unchanged gate | the fit condition |
| **`SourceReproduction`** *(research only)* | true airspeed **218.5–699.7 ft/s** (the source-exercised span) at **6,096 ± 1 m** only (the source's fixed-density altitude) | "coefficients EXTRAPOLATED from the M=0.6 fit (source-exercised, NOT aerodynamically validated)" whenever Mach ≠ 0.6 |

**Where the mode lives**, so that it cannot leak:
- The mode is a field of the **research profile** (`MavF15AfitResearchFlightDynamicsProfile.conditionMode`).
- `MavF15AeroModel` honours `SourceReproduction` only when that profile is the provider of the six-DoF body on the same GameObject. The exact 836 profile, a missing body, or a research profile the body does not fly all leave the gate **strict**.
- `MavF15AfitResearchFixedThrust` reads the same profile.

**What it widens:**
- **Nothing beyond what the source ran.** Below 218.5 ft/s, above 699.7 ft/s, or away from 6,096 m, it refuses.
- **Only the Mach bounds** of the research profile envelope. α and β are unchanged.

**Telemetry:** `MavF15AeroModel.debugExtrapolatedFromFitCondition`, `debugConditionMode`, and a status string beginning `SOURCE REPRODUCTION`.

**Exact NASA 836 is unaffected.** The exact source mode refuses in every condition mode (`[W7]`).

## 5. What SourceReproduction does NOT reproduce

- **Fixed density at any altitude.** The source has no altitude state. Maverick's density follows altitude, so the source semantics hold only at 6,096 m, and a free-flying body leaves that immediately. Freezing density for research reproduction is a WP-3B decision.
- **Maverick's density vs the source's.** Maverick's standard atmosphere at 6,096 m is compared against `RHO` in `[W10]`. The residual evaluation (`F15_TABLE_VII_EQUILIBRIUM_VALIDATION_V1.0.md`) uses the source's own `RHO` directly.
- **The α–V combinations the source actually visited.** The admitted speed band is a box. The source exercised it only along its continuation branches, so not every combination inside is "source-exercised".
