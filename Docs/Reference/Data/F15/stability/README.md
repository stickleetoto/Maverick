# F-15 research source stability — dataset (WP-3D)

> **Research source model only** (`F15_AFIT_BAUMANN_DAVISON_MACH06_20K_RESEARCH`, the AFIT/Baumann/Davison FUNX, no CAS). These are the open-loop eigenvalues of that model at Baumann's Table VII equilibria. They are **not** the real F-15, NASA 836, the production FCS or a Unity Rigidbody. Method and findings: `Docs/Reference/F15_RESEARCH_STABILITY_ANALYSIS_V1.0.md`.

**Origin.**
- **Generated by:** `MavF15ResearchStabilityValidation.ExportDataset`, in Unity 6000.3.16f1, through the FDM batch adapter.
- **Extracted with:** `extract_from_log.py`, which gives the usage.
- **Deterministic:** two separate Unity runs produced byte-identical files.
- **Scope:** the Table VII dataset itself (`../table_vii/`) is not modified.

**Units.** Angles in degrees, rates in rad/s, V in ft/s, eigenvalues in 1/s (imaginary part in rad/s). Jacobian entries are in the physical state units: rad, rad/s, ft/s.

| File | One row per | Columns |
|---|---|---|
| `f15_research_stability_table_vii.csv` | eigenvalue × equilibrium (1,360) | See the column list below. |
| `f15_research_stability_jacobians.csv` | equilibrium (170) | point, branch, stabilator; `A_<row>dot_<col>`, 64 entries, rows and columns in the order α, β, p, q, r, θ, φ, V |
| `f15_research_stability_step_audit.csv` | step factor × eigenvalue at 9 equilibria (720) | point, factor (× the chosen steps), mode, real, imag, \|Δλ\| to the chosen steps |
| `f15_research_stability_pitchfork_approach.csv` | approach point (58) | path (symmetric: V stepped; phi+ / phi−: φ stepped; table: printed rows), parameter, state, critical real eigenvalue, lateral fraction, signed eigenvector shape |
| `f15_research_stability_crossings.csv` | located crossing (8) | the pitchfork, 3 Hopf, 4 folds: parameter, final bisection bracket, Re at each end, state, crossing ω, lateral fraction, and, for folds only, the stabilator-extremum φ |

**Columns of `f15_research_stability_table_vii.csv`:**
- **Equilibrium:** point, branch, and the recovered state (stabilator, V, α, β, p, q, r, θ, φ).
- **Eigenvalue:** tracked mode name (A±, B±, C±, D, E), real, imag, natural frequency, damping ratio, lateral fraction.
- **Classification:** mode classification, equilibrium classification, unstable count.
- **Source comparison:** source classification, agreement.
- **Numerical and print uncertainty:** FD step spread, scaled-Jacobian difference, zero band, print spread, tracking ambiguity.

**Classification labels.**
- **STABLE / UNSTABLE:** the sign of Re is resolved.
- **NEAR_NEUTRAL:** Re lies inside the NUMERICAL zero band, max(1e-6 /s, 10 × the eigenvalue's own measured uncertainty). This is floating-point only.
- **Source classification:** the source prints no eigenvalues; every row is labelled from Table VII's caption.
- **Agreement:** AGREE / DISAGREE / UNRESOLVED.

**Cross-check.** `crosscheck_numpy.py` recomputes every eigenvalue from the Jacobians with numpy / LAPACK. The last run agreed to 4.2e-15 relative on all 1,360.
