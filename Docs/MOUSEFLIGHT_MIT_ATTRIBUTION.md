# MouseFlight Attribution

This fresh MAVERICK branch is based on the structure and concepts of the MouseFlight Unity example by Brian Hernandez.

The original MouseFlight package includes:

- `MouseFlightController.cs`
- `Plane.cs`
- `Hud.cs`

The original package states:

```text
Copyright (c) Brian Hernandez. All rights reserved.
Licensed under the MIT license.
```

This branch does not require the old MAVERICK physics stack. It implements an adapted version under the `MaverickFresh` namespace.
