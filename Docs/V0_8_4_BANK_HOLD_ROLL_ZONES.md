# MAVERICK Fresh v0.8.4 — Bank-Hold Roll Zones

## Problem

In v0.8.3, moving the mouse into the right/left roll zone continuously commanded roll rate.
That made the aircraft keep rolling forever.

Desired behavior:
- Mouse right side -> aircraft banks right to a target angle.
- It then holds that bank angle instead of endlessly rolling.
- Returning to the center rectangle -> wings level recovery.

## Main change

Screen roll zones now command a target bank angle instead of raw roll rate.

```text
right zone -> target bank angle
left zone -> target bank angle
center no-roll zone -> target bank angle 0
```

## New fields in MavMouseFlightJet

```text
useScreenRollZoneBankHold = true
maxScreenRollBankAngle = 58
bankHoldProportional = 0.032
bankHoldRollRateDamping = 0.22
invertScreenRollBankTarget = false
```

## HUD

The HUD now shows:

```text
BANK -34  BANKTGT -58  HOLD 0.42
```

Meaning:
- `BANK` = current signed bank angle
- `BANKTGT` = target bank angle from screen zone
- `HOLD` = roll command generated by bank-hold controller

## Tuning

### If it still rolls past the target too much

```text
bankHoldRollRateDamping = 0.32
bankHoldProportional = 0.024
maxScreenRollBankAngle = 50
```

### If it reaches the target too slowly

```text
bankHoldProportional = 0.045
bankHoldRollRateDamping = 0.18
```

### If right mouse banks left

```text
invertScreenRollBankTarget = true
```

### If bank angle is too steep

```text
maxScreenRollBankAngle = 42
```

### If bank angle should be more aggressive

```text
maxScreenRollBankAngle = 70
```

## Design intent

This is closer to War Thunder mouse aim behavior:

```text
mouse side position -> intended bank attitude
not
mouse side position -> infinite roll rate
```
